# Проверка модели через предпринимателей

1. Скопируйте `template.csv` в `responses.csv` (этот файл не публикуется — он в .gitignore) и удалите строку-пример.
2. Одна строка — одно место, которое знает предприниматель:
   - `id` — условный номер (E01, E02…), **без имён и названий магазинов**;
   - `category` — `food` (продукты), `pharmacy` (аптека), `catering` (кафе/общепит);
   - `place` — перекрёсток («Абая и Жансугурова») или координаты «45.0172, 78.3755»;
   - `slot` — когда у точки основной поток: `morning`, `day` или `evening`;
   - `business_status` — `good` (бизнес идёт хорошо) или `bad` (плохо / закрылся);
   - `sus_score` (0–100) и `tasks_completed` (0–3) — из теста приложения, если был;
   - `notes` — по желанию.
3. Запуск: `python3 research/entrepreneur_check.py research/entrepreneurs/responses.csv`

Скрипт находит ячейку модели, считает класс TSG (дефицит / баланс / избыток) в этот период и проверяет гипотезу «в ячейках дефицита бизнес идёт лучше»: точность, полнота, доля совпадений и 95 % интервал. Плюс средний SUS и долю выполненных заданий.

Только после одобрения IRB; участие добровольное, данные обезличены.
